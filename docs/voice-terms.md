> **免責:** これは各公式規約の**要約**であり、法的助言ではありません。**常に公式の規約本文が優先**します。規約は予告なく変わることがあります（実際、調査日の直前の 2026-10-25 に改定された声もあります）。**動画を公開・収益化する前に、必ず各規約 URL で最新版を確認してください。**ページを取得できなかったものや、規約どうしで書き方が食い違うものは **「要確認」** と書いています。推測では埋めていません。

## 表の読み方

- **商用利用:** 「可」はクレジットを表記すれば個人の商用利用（収益化した YouTube など）ができるという意味です。「可（条件付き）」は、企業・法人の利用や特定の用途に事前確認・申請が要るものです。「非商用のみ」は原則として商用利用できないものです（例外は備考に書いています）。
- **クレジット表記:** 規約が指定する文字列をそのまま書いています。VOICEVOX 公式サイトのキャラクター紹介に書かれた表記と、キャラクター側の規約に書かれた表記が違う場合は両方を載せています。迷ったときは**両方の条件を満たす書き方**（例: CV 名まで含める）を選んでください。
- **主な禁止事項・条件:** 抜粋です。全部ではありません。
- **規約URL:** VOICEVOX 公式サイトの各キャラクターページ（`https://voicevox.hiroshiba.jp/product/<id>/`）がリンクしている規約ページです。

### 1.1 VOICEVOX ソフトウェア自体の規約

出典: <https://voicevox.hiroshiba.jp/term/> と Q&A <https://voicevox.hiroshiba.jp/qa/>

- **許諾内容:** 「商用・非商用問わず利用することができます」。ただし**作成した音声を使うときは、各音声ライブラリ（キャラクター）の規約に従う必要があります**。作成した音声の利用を他者に許諾するときは、その人にも同じ条件を守らせる必要があります。
- **禁止事項:** ソフトウェアの無断再配布、逆コンパイル・リバースエンジニアリング、製作者や第三者に不利益をもたらす行為、公序良俗に反する行為。
- **クレジット:** 「ご利用の際は VOICEVOX を利用したことがわかるクレジット表記が必要です」。ソフト側の規約は書式を指定していませんが、Q&A と各キャラクター規約は **「VOICEVOX:キャラクター名」** の形を前提にしています。
- **書く場所（Q&A）:** 動画の場合は「動画の概要欄や動画内など」。音声だけの用途では音声の最初か最後にクレジットを入れます（キャラクター規約に指示があればそちらが優先）。
- **クレジットを省略したい場合（Q&A）:** 「キャラクター名」部分の省略ライセンスはキャラクター権利者が有償で提供していることがあり、「VOICEVOX:」部分の省略ライセンスも窓口はキャラクター権利者です。
- **モーフィング（Q&A）:** 2 つの声を混ぜた場合は両方の規約が適用され、**より厳しい規約が優先**されます。商用可の声と商用不可の声を混ぜると商用不可です。
- **複数キャラクターの表記方法:** VOICEVOX の規約・Q&A には**明記がありません**（→ §3）。
- 公式サイトのキャラクター紹介の定型文は「◯◯の音声ライブラリを用いて生成した音声は、『VOICEVOX:◯◯』とクレジットを記載すれば、商用・非商用で利用可能です」です。以下の表で「公式定型」と書いたものはこれを指します。

### 1.3 VOICEVOX ENGINE の API で規約を取れるか

ソースコード（`voicevox_engine/metas/metas.py`、`voicevox_engine/app/routers/character.py`）で確認しました。

- `GET /speakers` → `list[Speaker]`。フィールドは `name`、`speaker_uuid`、`styles[]`（`name`、`id`、`type`）、`version`、`supported_features.permitted_synthesis_morphing`（`"ALL"` / `"SELF_ONLY"` / `"NOTHING"`）。**規約の情報は含まれません。**
- `GET /speaker_info?speaker_uuid=<uuid>&resource_format=base64|url` → `SpeakerInfo`。フィールドは **`policy`（str、音声ライブラリの policy.md の本文＝利用規約の Markdown）**、`portrait`、`style_infos[]`（`id`、`icon`、`portrait`、`voice_samples`）。
  - FilmCraft はこの `policy` をアプリ内にそのまま表示できます。ただし**機械で読める「商用可否」や「クレジット文字列」のフィールドはありません**。Markdown を解析するか、本ドキュメントのような対応表を別に持つ必要があります。各 policy.md の実際の中身は調査していません（要確認）。
- 歌声用は `GET /singers` と `GET /singer_info`（同じ形式）です。
- `GET /downloadable_libraries` と `/installed_libraries` の要素（`BaseLibraryInfo`）は `name`、`uuid`、`version`、`download_url`、`bytes`、`speakers[]`（`speaker` と `speaker_info`、つまり ここにも `policy`）を持ちます。

### 2.4 AivisSpeech Engine の API でライセンスを取れるか（FilmCraft が自動で読むためのフィールド）

ソースコード（`voicevox_engine/model.py`、`voicevox_engine/aivm_infos_repository.py`、`voicevox_engine/app/routers/aivm_models.py`、aivmlib の `aivmlib/schemas/aivm_manifest.py`）で確認しました。

- `GET /speakers` → VOICEVOX 互換の `Speaker`。**ライセンスの情報はありません。**
- `GET /speaker_info?speaker_uuid=<uuid>` → `SpeakerInfo.policy`。AivisSpeech ではここに **`aivm_manifest.license`（ライセンス全文。Markdown かプレーンテキスト。ないときは空文字列）** が入ります（`policy=aivm_manifest.license if aivm_manifest.license else ""`）。1 つのモデルファイル内の話者はすべて同じライセンスです。
- `GET /aivm_models` → `dict[str, AivmInfo]`（キーはモデル UUID）、`GET /aivm_models/{aivm_model_uuid}` → `AivmInfo`。`AivmInfo` のフィールドは `is_loaded`、`is_update_available`、`is_private_model`、`is_default_model`、`latest_version`、`file_path`、`file_size`、**`manifest`（`AivmManifest`）**、`speakers[]`（`speaker` と `speaker_info`）です。
  - `AivmManifest` のフィールドは `manifest_version`、`name`、`description`、**`creators`（制作者名のリスト）**、**`license`（str か null。ライセンス全文）**、`uuid`、`version`、`speakers[]`（`name`、`icon`、`supported_languages`、`uuid`、`local_id`、`styles`）です。
  - **ローカルのエンジンには「ACML 1.0」のような種別 ID のフィールドはありません**（`license` は全文テキストのみ）。
- **種別 ID が欲しい場合:** AivisHub の公開 API `GET https://api.aivis-project.com/v1/aivm-models/{モデルUUID}` のレスポンス `model_files[].license_type`（`"ACML 1.0"` / `"ACML-NC 1.0"` / `"CC0"` / `"Custom"` / `"Internal"`）と `model_files[].license_text`（null 可）を使えます。`model_files[].creators` もあります。AivisHub に公開されていないモデル（`AivmInfo.is_private_model == true`）では使えません。

## 3. 複数の声を 1 本の動画で使う場合

- **VOICEVOX:** 規約・Q&A に複数キャラクターの書式は**明記されていません**。ただし各キャラクター規約は、それぞれが**自分のクレジット**（「VOICEVOX:キャラクター名」）を求めています。したがって**使った声をすべて、各規約が指定する文字列どおりに列挙する**のが確実です。
  - 例（1 行に 1 つ）:
    ```
    VOICEVOX:ずんだもん
    VOICEVOX:四国めたん
    VOICEVOX:もち子(cv 明日葉よもぎ)
    VOICEVOX:Voidoll(CV:丹下桜)
    ```
  - 「VOICEVOX:ずんだもん、四国めたん」のような省略形が認められるかは、公式の明記が見つからなかったため**要確認**です。FilmCraft は省略形を出力しない方針が安全です。
  - CV 名が必須または推奨の声（もち子さん、Voidoll、ユーレイちゃん、櫻歌ミコなど）は、CV 名を省かないでください。
  - **モーフィング**した声は、混ぜた両方の規約が適用され、厳しいほうが優先されます（両方のクレジットを書いてください）。
  - 猫使アル・ビィを両方使う場合は、規約にある「VOICEVOX:猫使アル/猫使ビィ」を 1 行で書けます。
- **AivisSpeech:** ACML / ACML-NC / CC0 にはクレジットの義務がありません。それでも、どのモデルを使ったかを追えるように「AivisSpeech:まお」「AivisSpeech:コハク」のように 1 声 1 行で書くのを勧めます（この書式は任意で、公式が指定したものではありません）。Custom ライセンスの声は、その `license_text` の指示に従ってください。
- **両方のエンジンを混ぜる場合:** VOICEVOX 側の行（必須）と AivisSpeech 側の行（任意・推奨）を並べて書きます。

## 4. FilmCraft でクレジットを動画と説明欄に入れる

FilmCraft はナレーションの WAV ごとに使った声を記録します（プロジェクト項目のメタデータ `Narration Credit` と `Narration Voice`。保存すると残ります）。スクリプトやアニメ化の経路（`speech.synthesize`、`script.synthesize` → `anime.build` / `anime.run`）で AivisSpeech / VOICEVOX を使った声も、同じメタデータを取り込んだ音声に記録します（Qwen3-TTS の声はクレジットを記録しません。声を複製する場合は、元の話者と録音の権利者の同意が必要です。[text-to-speech.md](text-to-speech.md#which-route)）。シーケンスで使っている声を 1 声 1 行・重複なしで集めます（タイムラインから消したナレーションは含めません）。

- **動画内（エンドロール）:** 「グラフィックとタイトル ▸ ナレーションのエンドロールを追加」（`tts.addCreditRoll`）。シーケンスの最後に「音声」の見出しとクレジットを流すグラフィッククリップ「Narration Credits」を追加します。もう一度実行するか、ナレーションを追加生成すると、新しいクリップを増やさず同じクリップの文字を更新します（名前を変えたりコピーしたりしても同じクリップとして見つけます）。見出しは 設定 ▸ 外観 ▸ 言語 に従い（CLI / MCP でも同じ。「自動」でシステムの言語が分からないときは日本語）、一度作ったら変わりません。追加生成での自動更新では、指定したタイトルと追加行、選んだフォント、置いた位置はそのままです。手で編集した文字とロックしたトラック上のクリップは変更しません（「エンドロールに追加」を実行すると文字を作り直します）。エンドロールがあるとき、「ナレーションを生成」の「エンドロールを更新」のチェックを外すと更新しません。「ナレーションを生成」の「最後にエンドロール」、または 設定 ▸ ナレーション ▸「最後に声のクレジット(エンドロール)を追加」で、生成のたびに自動で入れられます。
- **説明欄:** 「グラフィックとタイトル ▸ ナレーションのクレジットを書き出し」（`tts.exportCredits`）。クレジットの行を UTF-8 のテキストファイルに書き出します（相対パスはプロジェクトのフォルダー、未保存ならナレーションのフォルダーが基準。拡張子がなければ .txt を付けます。開いているプロジェクトや .txt 以外の既存ファイルは上書きしません）。AivisSpeech の声は、エンジンが報告したモデル名・ライセンス・AivisHub のページも書きます。
- **表記を変えたい場合:** CV 名が必要な声（もち子さんなど、§1.2）は、メタデータパネルで `Narration Credit` を規約どおりの文字列（例: `VOICEVOX:もち子(cv 明日葉よもぎ)`）に書き換えてください。エンドロールと説明欄のテキストはその文字列を使います。
- 詳しくは [narration.md](narration.md#credits-in-the-video-and-the-description) を見てください。
