# 小説からアニメを作る — 必要機能の検討

状態: **検討メモ**（2026-11-05）。実装はまだ無い。FilmCraft の既存機能で何が賄え、何が欠けているかを
工程順に整理し、優先度を付ける。クリーンルーム・ピュア Rust・オープンライセンスの制約
（[AGENTS.md](../AGENTS.md)）の下で現実的な範囲に絞っている。

想定する成果物は「ボイスドラマ＋立ち絵＋背景＋字幕」型の 2D アニメ（いわゆる動画小説 /
ビジュアルノベル風）で、作画アニメの自動生成は対象外。

## 1. 工程

```
小説テキスト ─► 台本 ─► 絵コンテ / ショットリスト ─► 素材（音声・画像・SE/BGM）
            ─► 自動アセンブル（シーケンス）─► 口パク・カメラワーク ─► 字幕・ミックス ─► 書き出し
```

台本を**唯一の上流データ**にし、下流のクリップはすべて台本の行 ID を持つ。台本を直したら
差分だけ再生成できることが、繰り返し作業の前提になる。

### 1.1 脚本化（小説 → 台本）

| 機能 | 内容 |
|---|---|
| テキスト取り込み | txt / epub / 青空文庫形式（ルビ記法 `｜漢字《かんじ》`、傍点、縦書き指定）。章・場面・段落の構造を保つ。 |
| 台詞と地の文の分離 | 「」『』による台詞抽出、話者推定、地の文のナレーション化。 |
| ト書き抽出 | 場所・時間帯・天候・感情・登場人物の入退場を場面ごとに付ける。 |
| 台本モデル | **実装済み**（[script.md](script.md)）。プロジェクトの外の独立 JSON ファイル `*.fcscript.json`。内容：場面 → カット → 行（台詞 / ナレーション / SE / BGM 指示）。各行に話者、感情、読み仮名、推定尺を持つ。 |

話者推定とト書き抽出は LLM が本命。FilmCraft 内にモデルは持たず、**MCP 経由で外部エージェント
が台本を書き込む**コマンド群（`script.*`）を用意する。手で直せるテーブル UI（Text パネルの新タブ）
も要る。

### 1.2 絵コンテ・設計

| 機能 | 内容 |
|---|---|
| ショットリスト生成 | 台本の行から 1 カット = 1 行（または数行）を自動で切り、尺は後述の TTS 結果で確定する。 |
| 絵コンテパネル | サムネイル＋台詞＋秒数の一覧。順序入替、尺の合計、場面ごとの小計。 |
| カメラワーク指示 | カットごとに寄り / 引き / パン / ズーム / 固定をプリセットで選ぶ。 |
| キャラクター設定表 | 名前、声（TTS の話者 ID とパラメータ）、口調、立ち絵セット（表情 × 口形）。 |
| 背景台帳 | 場所 × 時間帯 → 背景画像。ト書きの場所名から引く。 |

### 1.3 素材生成

| 機能 | 現状 | 内容 |
|---|---|---|
| **音声合成（TTS）** | あり（外部 Qwen3-TTS） | 話者別の声、感情・速度・ピッチ、読み仮名とアクセント指定、**単語 / 音素タイムスタンプ出力**。Whisper と同じ扱い（`crates/speech` に `Synthesizer` trait、candle 推論、初回に検証付きダウンロード、重みは同梱しない）。オープンライセンスの VITS / Piper 系が候補。日本語の読み（漢字 → かな、アクセント）が最大の難所で、辞書もオープンライセンスのものに限る。 |
| 画像生成 | 無し | 拡散モデルをローカル pure Rust で回すのは重く、ライセンスも難しい。**スコープ外**とし、外部ツールで作った画像の取り込みに徹する。 |
| レイヤー付き画像 | PSD は合成 1 枚のみ。**不要**（表情ごとの PNG をそのまま使う。台本の `expressions` が対応表） | 立ち絵の差分（表情 × 口形 × ポーズ）をレイヤー名の規約で読み、1 つの「キャラクター素材」として扱う。 |
| SE / BGM ライブラリ | 無し | ト書きのキーワード（雨、足音、扉）からタグ検索。素材自体はユーザーのフォルダを指す。 |

### 1.4 自動アセンブル

| 機能 | 現状 | 内容 |
|---|---|---|
| 台本 → シーケンス | Automate to Sequence のみ | カットごとに背景（V1）、立ち絵（V2–）、音声（A1–、話者ごとにトラック）、字幕（キャプショントラック）を Tick 精度で並べる。 |
| 尺の自動決定 | — | 台詞音声の長さ＋間（ま）のルール（句点 0.4 s、場面転換 1.0 s など、設定可能）でカット尺を出す。 |
| 差分再生成 | — | 台本の行 ID でクリップを追跡し、変わった行だけ TTS と配置をやり直す。手で動かしたクリップは守る。 |
| 場面転換 | トランジション 84 種あり | 場面境界に既定のトランジション（ディゾルブ / 暗転）を自動で付ける。 |
| BGM ダッキング | Essential Sound にあり | 台詞トラックを基準に BGM を自動で下げる。既存のダッキングをそのまま使う。 |

### 1.5 立ち絵アニメーション

| 機能 | 現状 | 内容 |
|---|---|---|
| **口パク** | 無し | TTS の音素タイムスタンプ（無ければ音量包絡）から口形差分（あ・い・う・え・お・閉）を切り替える。簡易版は母音 5 種＋閉で十分。 |
| 表情切替 | 無し | 行の感情タグから表情レイヤーを選ぶ。手動上書き可。 |
| 自動の生っぽさ | — | 瞬き（ランダム間隔）、呼吸の上下揺れ、首の微小な傾き。キーフレーム生成として実装し、既存の Transform で動かす。 |
| カメラワーク | Transform プリセットあり | 寄り / 引き / パン / Ken Burns を 1.2 の指示から自動でキーフレーム化。 |

これは「キャラクター素材クリップ」という新しいクリップ種別（PSD レイヤー集合＋状態の時系列）と
して持つのが素直。レンダリングは既存の静止画合成で足りる。

### 1.6 字幕・仕上げ

| 機能 | 現状 | 内容 |
|---|---|---|
| 台本からの字幕 | キャプション（SRT/VTT/TTML…）あり | 文字起こし不要。行の文字と TTS の時刻からそのままキャプションを作る。 |
| ルビ | あり（青空文庫記法 `｜漢字《かんじ》`、縦書きも可） | 台本の行をそのままグラフィッククリップに流せる。キャプショントラック（SRT/VTT 等）はルビを持てないので、ルビ付き字幕はグラフィッククリップとして出す。 |
| ラウドネス・ミックス | あり | ナレーション正規化、BGM ミックス、書き出し時のラウドネス正規化は既存機能で完結。 |
| 書き出し | あり | 章ごと / 場面ごとの範囲書き出しをプリセット化。 |

### 1.7 エージェント駆動

全工程をエンジンコマンドにし、MCP から「この章を動画にする」まで通せるようにする。
台本の生成だけは外部 LLM の仕事なので、`script.*` コマンドは**書き込み口**として設計する
（読む・差し替える・行単位の更新）。

## 2. 現状とのギャップ（優先順）

| 機能 | 現状 | 優先 | 主な置き場 |
|---|---|---|---|
| TTS（話者別・声のクローン） | あり：`speech.synthesize` が Qwen3-TTS を外部 Python として実行（[text-to-speech.md](text-to-speech.md)）。タイムスタンプは Whisper で後付け | 済 | `crates/speech`, `tools/qwen3-tts` |
| 台本モデル＋ `script.*` コマンド | あり：`script.validate` / `pickVoices` / `synthesize` / `lipsync`（[script.md](script.md)）。取り込み元ごとの変換器は未着手 | 済（変換器は別） | `crates/project`, `crates/engine` |
| 自動アセンブル（台本 → シーケンス、差分再生成） | 音声の差分再生成は済（`script.synthesize` のマニフェスト）。配置は未着手 | 高 | `crates/edit`, `crates/engine` |
| キャラクター素材クリップ＋口パク・表情 | 口パクの解析は済（`lipsync.analyze`、音量包絡の 2〜3 段階）。クリップ種別と切り替えの配置は未着手 | 高 | `crates/project`, `crates/render` |
| 絵コンテパネル | 無し | 中 | `crates/ui-egui` |
| SE / BGM タグ検索 | 無し | 低 | `crates/ui-egui`（メディアブラウザ） |
| 画像生成 | 無し | 対象外 | 外部ツールに委ねる |

## 3. 判断の根拠

- **TTS を最優先**にするのは、音声が無いと尺が決まらず、以降の全工程（配置・口パク・字幕）が
  動かないため。文字起こし（Whisper）と同じ基盤（candle、検証付きダウンロード、ライセンス台帳）
  に乗せれば、新規の仕組みは最小で済む。
- **画像生成を外す**のは、クリーンルームとオープンライセンスの制約に加え、ローカル pure Rust で
  実用速度が出ないため。FilmCraft は「素材を受け取って組み立てる側」に集中する。
- **台本を上流データにする**のは、小説は何度も推敲されるものだからで、全部作り直しでは実用に
  ならない。行 ID による追跡が差分再生成の鍵になる。
- 日本語固有の難所は TTS の**読み・アクセント**。ルビは既にテキストエンジンにある。

## 5. 自動化できるレベルでの現状

目標は「素材フォルダとシナリオを渡したら、人手の操作なしでシーケンスと動画ができる」こと。人が見るのは最後の 1 回だけにする。詳細は [script.md](script.md)。

| 段階 | 状態 | 備考 |
|---|---|---|
| 台本の定義と検査 | 済 | `script.validate`。分岐は `route` / `requires` / `when` で検査 |
| 取り込み元の変換（小説・ゲーム） | 未着手 | タイトルごとの外部スクリプトが台本 JSON を書く。FilmCraft 本体には入れない |
| 参照音声の自動選択 | 済 | `script.pickVoices`。元音声と台詞テキストの対から、長さ・平静さ・話速で選ぶ。Whisper は不要 |
| 欠けた音声の合成 | 済 | `script.synthesize`。録音のある行は触らず、変えた行だけ再合成 |
| 口パク | 済 | `script.lipsync` で開閉を解析し、`anime.build` が開いた口の画像を重ねる。モデル不要・決定的 |
| 台本 → シーケンス配置 | 済 | `anime.build`。背景・立ち絵・口・瞬き・声・音楽・効果音・字幕。背景のゆっくりした寄り。1 回の取り消しで元に戻る |
| 自動検査 | 済 | `anime.check`。ギャップ・音声の重なり・無音・字幕の長さと速さ・音量差・オフライン |
| 一括実行 | 済 | `anime.run`。検証 → 参照選択（任意） → 合成 → 配置 → 検査 → 書き出し（任意）。合成はキャッシュされるので 2 回目は変えた行だけ |
| 立ち絵の動き・複数人の同時表示・トランジション | 未着手 | 立ち絵は静止（口と瞬きの画像が揃う利点）。場面転換はカット |
| 母音ごとの口形 | 未着手 | 読みと音声の対応付けが要る |
| ゲーム台本の変換器 | 汎用部は済 | `tools/game2script/`。書式をプロファイル（正規表現）で記述し、読めなかった行を報告する。タイトル固有のプロファイルは、シナリオの実物（数十行と素材のフォルダ構成）を見てから書く（[game-import.md](game-import.md)） |
